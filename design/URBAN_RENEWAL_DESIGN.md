# 城市更新测绘扫描与巡检具身机器人方案

版本：V1概念方案。日期：2026-11-06。面向既有建筑现状采集、更新施工前后对比、日常巡检和病害线索复查。共用本项目的机载算力、工具快换、离线证据日志与三维展示，单独建立室内导航和测绘验收流程。当前没有真实扫描仪驱动、BIM自动建模或实测测绘精度。

## 一 产品配置

|配置|任务|机体与模块|当前边界|
|---|---|---|---|
|U-M 城市测绘扫描型|房间、走廊、地下空间点云与影像覆盖|轮足底盘、固定扫描桅杆、三维扫描仪安装座、全景相机、IMU、机载存储和时间同步|适用已确认可滚行地面；不默认能爬楼梯；扫描仪型号、精度、续航待选型|
|U-I 城市近距巡检型|墙面/设备近距成像、裂缝/渗漏/热异常线索与接触检测|足式底盘、四轴轻型臂、标尺照明相机或柔顺接触探头，可选标定热像|足式楼梯能力需验证；接触检测原理待选型；不自动判定建筑结构安全|

U-M不强制搭载机械臂以减少遮挡、振动与载荷；U-I优先轻载和重复观察。两者不是将所有仪器同时堆装。近距相机预算0.6 kg、接触探头0.8 kg仅为设计预算；实际采购后按完整BOM、重心与关节力矩复核。

高层外立面、幕墙和屋顶另用经验证的高空作业平台/其他采集设备协作。现有0.7 m轻型臂和固定短桅杆不能承担整栋高层外墙扫描任务，不能通过三维外观推导可达高度。

## 二 业务闭环

1. 建立楼栋、楼层、房间和构件清单，明确测绘成果用途、区域边界与精度要求。确认通路、门槛、玻璃、楼梯口、临边和人员动态区。
2. 建立坐标控制与独立检查点，记录仪器标定、时间同步和相机/雷达外参版本。重复巡检应复用可恢复的基准，不直接拿每次独立SLAM坐标相减。
3. 先进行低速探索和覆盖规划，生成导航地图；需要测绘级成果的区域采用停稳、锁紧后定站扫描并补充遮挡部位。导航地图和测绘成果分别验收。
4. 点云去噪、运动畸变处理、配准与闭环后，将点云注册到建筑坐标；用未参与配准的检查点评估误差和系统偏差。ICP残差小不能代替绝对精度验收。
5. 用标定相机采集病害候选，保存原图、尺度、距离、视角、光照和构件位置。热异常/裂缝候选转人工复核，现场复测后再形成结论。
6. 对接既有BIM或现状模型，关联构件GUID、问题单、照片和复查时间。保留模型版本及变更记录，避免将点云自动套入不存在的构件。
7. 更新施工前后使用同一基准复测，并将遮挡、未测区、低置信区和变更区域分开交付。

## 三 软件与数据架构

```text
激光/全景影像/IMU/可选热像及接触探头
  → 时间同步与外参标定
  → LIO/VIO定位及局部地图（尚未实现）
  → 覆盖规划/避障/安全门控 → 底盘与机械臂（需真实驱动）
  → 原始数据留存 → 配准/控制点检查 → 点云与现状模型
  → 构件关联/候选问题单 → 人工复核 → 复查与版本对比
```

坐标链按 `building/map → odom → base_link → sensor/tool` 定义，每一变换都带单位、时间、标定版本及不确定度。建筑控制基准与楼层局部坐标另行定义，不以RTK在室内可用为前提。参考 [ROS REP-105](https://github.com/ros-infrastructure/rep/blob/master/rep-0105.rst)。

建议交付原始点云、注册点云（按系统支持选择E57/LAS/LAZ等）、影像、覆盖图、独立检查点误差表、标定记录、构件关联与问题单；BIM交换采用项目约定的IFC版本。IFC是开放的建筑信息交换标准，但格式支持不等于本项目已实现自动建模，参考 [buildingSMART标准目录](https://standards.buildingsmart.org/)。

记录最小字段：project_id、building_id、floor_id、room_id、element_guid（可空）、observation_id、采集时间和时区、sensor_id、calibration_id、frame_id、pose与协方差、原始文件哈希、候选类别、质量标志、复核人和复查关联ID。没有标定或坐标来源的影像只作线索，不自动输出尺寸。

## 四 指标与验收

不将点云密度、SLAM闭环误差或相机像素数直接宣传为测绘精度。先确定成果用途与误差预算，再选扫描仪和作业方式。激光扫描误差与计量溯源可参考 [NIST扫描仪性能评估综述](https://www.nist.gov/publications/performance-evaluation-terrestrial-laser-scanners-review)。

|对象|需要记录的指标|验收方法|
|---|---|---|
|导航|定位漂移、最小间距、停车距离、掉帧停车、楼梯/临边误判|已知路线和动态行人替代物，逐情形记录成功/失败|
|测绘|独立检查点RMSE、偏差、最大误差、覆盖完整性、未测区|独立控制测量，不使用参与配准的同一批点自证|
|重复巡检|同一构件重定位误差、同视角复拍率、时间基准|跨日期、重新启动和不同光照复测|
|裂缝候选|检出率、误报率、标尺下测宽误差与适用距离|有标注样本及真实标尺/独立量具；未标定前不输出毫米结论|
|热异常|温度/辐射率配置、环境反射影响、复查一致性|标定源和人工复核；温差不直接等于内部缺陷|
|数据交付|坐标/单位一致、构件关联、文件完整、可追溯性|哈希与版本校验，随机抽取问题单回溯原始证据|

建议先选择一个楼层作为示范区，以房间、走廊、玻璃、门槛、弱纹理、弱光和临边替代装置构建测试集，再确定项目数值门槛；本方案不承诺尚无实测依据的毫米级精度。

## 五 研发阶段

- 第一阶段：采购/确定实际底盘和传感器接口，完成手动采集、坐标基准、标定与离线数据流程。先形成可检查的实测小样。
- 第二阶段：同一楼层的定位、覆盖导航、停站扫描与重复到点；加入玻璃和临边失效保护。当前森林仿真结果不能直接迁移为楼宇能力。
- 第三阶段：构件关联、候选问题单、人工复核和复查闭环，再扩展地下空间和跨楼层任务。
- 第四阶段：根据标注与检查点结果决定是否训练视觉模型、学习式运动或扫描位姿策略；没有真实数据前不声称已具备城市更新自主作业能力。

当前交付为共享模块配置、两种城市机型三维概念、工具布局和本方案。真实LIO/VIO、点云处理、覆盖导航、IFC/BCF导入导出与病害检测均为后续实现项。
