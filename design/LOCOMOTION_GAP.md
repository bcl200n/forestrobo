# 与 ETH 野外运动控制研究的差距

参考：[项目页面](https://leggedrobotics.github.io/rl-perceptiveloco/)，[论文及补充材料](https://arxiv.org/html/2201.08117v1)。本文对照当前实际实现，不把设计方案或新增文件当作已验证能力。

当前最紧迫的缺口是可靠的底层速度跟踪。训练结果见TRAINING_REPORT.md；现有模型不能证明森林自主通过能力。轮足接触模型的差速转向响应需要先校准，足式CPG也没有通过独立回合验证。

该研究将教师策略、受噪声影响的学生策略、循环感知融合与实机试验连接起来。我们增加的观测历史、噪声、故障和评测只补了实验基础，尚未实现其核心教师蒸馏和门控循环信念编码器。水平距离射线也不能代替足端周围高程感知。

建议按以下依赖顺序推进，每一步独立验收：

1. 选定真实足式平台或已验证的底盘速度接口，补质量惯量、关节方向、转矩、延迟、摩擦与转向响应辨识；轮足另建接触/转向基线。
2. 将低层任务独立成纵向、横向与偏航速度跟踪，加入抬脚、足端滑移、关节力矩和外推扰动测试。先验证无外感知条件下的稳健运动。
3. 在仿真中提供特权地形、接触和扰动信息，训练可靠教师；教师未通过独立测试时不启动学生蒸馏。
4. 加入局部高程图足端采样与量测置信信息，训练循环学生与感知门控，对地图漂移、软植被、缺测和连续遮挡做结构化测试。
5. 再接局部地形规划、机载定位与断联任务管理，开展仿真规则外和实机逐级测试。论文的运动控制结果不能替代通信、定位和完整任务栈验收。
6. 机械臂先限定为行走时收拢、站稳后作业；加入真实臂/工具/样品质量与反力后，重新评估稳定性。动态臂腿协同是额外研究内容。

多机型网页适合任务配置比较与结构交流，不能减少运动控制、感知融合和实机验证的工作量。目前没有给出“还差几个月”或“达到百分之几”的证据。
